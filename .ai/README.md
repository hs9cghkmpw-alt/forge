# .ai/

このリポジトリを**開発する際にAIコーディングエージェント（Claude Code等）が参照する**
共通設定・プロジェクトコンテキスト置き場。プロダクト自体のAI機能（`backend/app/ai/`）とは無関係。

- `CONTEXT.md` — アーキテクチャ・命名規則・禁止事項など、どのAIエージェントにも共通する前提知識
- 将来、ツール固有の設定（例: 特定エージェントの設定ファイル）もここに集約する

## `.agents/` との違い
- `.ai/` — **全エージェント共通**のプロジェクト知識（1つ）
- `.agents/` — **役割ごとに異なる**エージェント定義（複数）
