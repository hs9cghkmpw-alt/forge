# PROMPTS/

**プロダクトが実行時に読み込むプロンプト本文**の置き場（`backend/app/ai/prompts/`から参照される）。
ここはコードではなくコンテンツだが、Forgeの中核的な「振る舞い定義」であるため、
`backend/app/` の奥に埋めずルート直下で独立管理する（変更履歴・レビューをコードと同等に扱うため）。

- `system/` — AIの役割・制約を定義するシステムプロンプト（例: 「JSONのみを返す」という大原則の実文言）
- `templates/` — 会話 → JSON UI Schema生成など、用途別のプロンプトテンプレート

## 運用ルール

- 1ファイル1プロンプト。ファイル名にバージョンを含める（例: `generate_ui_schema.v1.md`）。
- 破壊的にプロンプトを変更する場合は新バージョンファイルを追加し、旧バージョンは残す
  （AI Improveが過去バージョンとの比較を行える可能性があるため）。
- **なぜ`docs/prompts/`と分離するか**: `PROMPTS/`はコードが読み込む実体（本番資産）、
  `docs/prompts/`はプロンプト設計の意図・評価基準・変更理由を記録する人間向けドキュメント。
  役割が違うため混在させない。
