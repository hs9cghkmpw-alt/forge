### hierarchy / primary visibility

**Before**

* 収入 `320,000` が最大・濃色（`metric.primary`）
* 残高 `193,000` は小さい（`metric.secondary`）
* 支出 `127,000` はマゼンタ（`finance.expense`）

利用者が言った「残高をもっと目立たせて」が、**実際に一番目立つ**形で

## 撮影環境の制約（正直な申告）

この container の network policy は `gstatic.com` を拒否する。
そのため**そのままでは2通りの形で真っ白な画像になる**。

1. **CanvasKit が CDN から取れない** → engine が起動しない
   → build が吐いた `canvaskit/` を指すよう設定した（回避ではなく、
     Flutter が公式に持つ `canvasKitBaseUrl`）
2. **既定フォント(Roboto)が取れない** → **文字が1つも描かれない**
   → 撮影時だけ、同じ要求へローカルの日本語フォント(IPAGothic)を返した

### だから字形は本番と違う

上の 2 により、画像の**字形は IPAGothic** であり、本番の
`fontFamily: 'Helvetica'` → 実際に載る Roboto/system font とは違う。

**見てよいのは配置・重なり・はみ出し・階層であって、字形ではない。**
字送りが変わるので、極端に長い文字列での折り返し位置は本番と一致しない
可能性がある。

### 途中で「真っ白なPNG」を1回作った

最初の撮影は engine 未起動のまま撮っており、**4枚とも真っ白**だった。
ファイルは生成されているのでコマンドは成功して見える。
**画像を開かなければ、これを「実描画の証拠」として提出していた。**

`AGENTS.md` の「PNGを生成しただけを Visual Review と呼ばない」は、
この形の失敗を指している。

## 見つけた製品側の問題

**Web build に同梱フォントが無い**（`TECH_DEBT.md` TD75）。

`frontend/pubspec.yaml` は `fonts:` を宣言しておらず、
`ForgeTheme` は `fontFamily: 'Helvetica'` である。Flutter Web
(CanvasKit) は system font を使わないので、`fonts.gstatic.com` へ
届かない環境では**文字が1文字も表示されない**。

* 社内ネットワーク・オフライン・広告ブロッカー・GFW 等で起こりうる
* 「遅い」ではなく「**何も出ない**」という壊れ方をする
* 日本語を主に扱うので、フォント差し替えの影響が大きい

今回は撮影のための差し替えで回避したが、**製品側は直っていない。**
