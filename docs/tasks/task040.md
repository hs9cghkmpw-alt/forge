# Task040 — Forge UI刷新: CEO提示モックアップへのUI反映

## 依頼内容
CEOから、6ステップのUIフロー(ホーム画面→「例を見る」→入力反映→
生成中→完成→生成されたアプリのイメージ)を示すモックアップ画像が
提示され、「今の中身でUIだけこれに寄せる」形でForgeアプリへ反映する
ことを依頼された。続けて、実際のアプリへの反映とレポート作成を依頼
された。

## 行ったこと
- `frontend/lib/`配下の関連ファイル(テーマ・ホーム画面・例選択
  Bottom Sheet・生成フロー画面・Fマーク共有Widget)を確認し、既に
  2026-07-16付でモックアップに合わせて更新済みであることを検証した。
- 既存のE2Eテスト(`kids_checklist_generation_flow_test.dart`・
  `survey_form_validation_flow_test.dart`)が、UI変更(Confirm画面の
  廃止・送信ボタンの変更)により実際には失敗する状態のまま残っている
  ことを発見し、新しいUI操作に合わせて修正した。
- 修正作業中、自分自身の編集ミス(置換範囲不足による旧内容の重複残存)
  をbrace/paren数の機械的確認で発見し、修正した。
- 変更ファイル一覧・既知の制限・CEO実機確認手順を含む実施レポート
  (`FORGE-UI-REFRESH-report.md`)を作成した。

## 変更理由
CEOの明示的な依頼に基づく。E2Eテスト2件の修正は、UI変更に伴う既存
テストの破損を防ぐために必須の対応だった(「既存テストを維持する」
という一貫した方針に基づく)。
