# Forge Docs

このディレクトリはForgeプロジェクトの設計ドキュメント集です。
新しく参加するエンジニア・AIエージェントは、以下の順番で読むことを推奨します。

0. **HANDOFF.md** — **最新の申し送り。まずここを読む。**
   直近でやったこと・今の状態・次にやること・CEOへの依頼が全部ある。
   パスは固定で、作業のたびに上書き更新される
1. **ARCHITECTURE.md** — 全体構造・レイヤー設計・依存関係のルール
2. **API.md** — バックエンドAPIの設計方針
3. **DATABASE.md** — Supabase上のデータ設計方針
4. **AI.md** — AIとJSON UI Schemaの関係、AIの責務範囲
5. **ROADMAP.md** — 今後どの順番で機能を積み上げるか

## AIエージェント向け（Claude / ChatGPT）

このリポジトリは**複数のAIが同じGitHubを見て**作業する。したがって
**チャットの中だけで報告してはならない**——チャットは他方から見えない。

* 最新状況は必ず `docs/HANDOFF.md` に書く（パス固定・毎回上書き）
* 詳細は `docs/reports/<TASK名>-report.md`
* 作業ルール全体は リポジトリ直下の `CLAUDE.md`
* **最上位方針は `PRODUCT-DIRECTION.md`（変更不可）**

## ドキュメント運用ルール

- 仕様を変更する場合は、コードより先に該当ドキュメントを更新する（Docs as Source of Truth）。
- 「決定事項」と「検討中の提案」は明確に分けて記載する。
- 破壊的変更（DBスキーマ変更・API契約変更）は必ずここに変更履歴を残す。
