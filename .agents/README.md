# .agents/

複数のAI開発エージェントに**役割分担**させて開発する場合の、役割ごとの定義置き場。
`.ai/CONTEXT.md`（全員共通の前提）を読んだ上で、各エージェントは自分のファイルの
スコープ（担当ディレクトリ・やって良いこと/悪いこと）のみに従う。

- `backend-agent.md` — `backend/`のみを担当するエージェントの定義（プレースホルダー）
- `frontend-agent.md` — `frontend/`のみを担当するエージェントの定義（プレースホルダー）
- `docs-agent.md` — `docs/`の整合性維持を担当するエージェントの定義（プレースホルダー）

現フェーズでは役割分担運用そのものを未確定のため、プレースホルダーのみを用意する。
